## 授業について

### 授業の日程はどこで確かめられますか

全14回の日程は、Wikiの[授業の日程と進行](../../../wiki/course/schedule.md)にあります。授業は水曜日3限で、2026年9月30日から2027年1月20日までです。各回で実際に何をしたかは、授業サイトの[ログのページ](https://sites.google.com/view/2026ats/ログ)に記録されます。2026年10月7日時点で、第4回以降の内容はまだ決まっていません。11月18日は日程表に含まれておらず、授業がないと思われますが、確認中です。

### 課題の提出先や評価の方法は決まっていますか

2026年10月7日時点では、成績評価の方法や課題の提出先（[WebClass](../../../wiki/campus/webclass.md)を使うかどうかなど）は、まだWikiに資料がありません。授業での案内に従ってください。分かりしだいWikiに反映されます（[全体の概観](../../../wiki/overview.md)の「確認が必要な点」）。

### プログラミングの経験がなくても大丈夫ですか

大丈夫です。この授業はプログラミングの経験を前提にしていません（[授業の概要](../../../wiki/course/course-overview.md)）。プログラムが必要になったら、AIエージェントに日本語で頼んで作ってもらえます。その場合も、何を作ってもらったのかを説明できるようにしておきましょう。

### 個人とチーム、どちらで取り組めばよいですか

プロジェクトには個人でもチームでも取り組めます。チームの作り方などは、2026年10月7日時点ではまだ決まっていないので、授業での案内に従ってください。それぞれのよいところと注意点は[プロジェクトの進め方](project-workflow.md)にまとめています。

## 学内の環境について

### 教室でWi-Fiがつながらない、遅い

世田谷キャンパスの教室Wi-Fiは、2026年10月時点で、教室の定員内であればWebClassなどはおおむね使える状態とされています。ただし、定員近くの人数では余裕が少なく、設備の増強は2026年末の見込みです（[学内Wi-Fi](../../../wiki/campus/campus-wifi.md)）。

- 教室が混んでいるときは、使っていないスマートフォンの電源を切る（大学からそう求められています）。
- 大きなファイルのダウンロードや動画など、通信量の多い作業は授業時間外に行う。
- 接続の問題が続くときは、日時、教室名、起きたことを添えて、情報基盤センターSC（[itcsc@tcu.ac.jp](mailto:itcsc@tcu.ac.jp)）に連絡する。

学外から学内のサービスに接続するには、eduroamやVPNが使えます（[ネットワーク接続の案内](https://www.itc.tcu.ac.jp/network/vpn/)）。

### TCUアカウントや多要素認証で困っています

TCUアカウントは大学の各サービスに共通のアカウントで、Microsoft 365 Copilotを使うときにも必要です。設定の手順は情報基盤センターの[TCUアカウント](https://www.itc.tcu.ac.jp/tcuaccount/)と[多要素認証](https://www.itc.tcu.ac.jp/mfa/)の案内を見てください。多要素認証の具体的な手順については、2026年10月7日時点ではまだWikiに資料がありません（[TCUアカウントと多要素認証](../../../wiki/campus/tcu-account.md)）。解決しないときは、情報基盤センターのウェブサイトにある問い合わせ先に相談しましょう。

### ノートパソコンが壊れました

情報基盤センターに[PCの修理・貸し出し](https://www.itc.tcu.ac.jp/student/pcrepren/)の案内があります。学生によるPCの相談窓口の[PCサポーター](https://www.itc.tcu.ac.jp/pcsupporter/)もあります（[学内のITサービス](../../../wiki/campus/it-services.md)）。作業中のファイルをGitHubにこまめにコミットしておけば、パソコンが壊れても、ほかのパソコンから続きを始められます。

## GitHubについて

### GitHubの画面が英語で分かりません

2026年10月時点で、GitHubのウェブサイトには公式の日本語の画面がありません。必要な操作（リポジトリの作成、ファイルと履歴の確認、招待の承諾など）に絞って覚えれば十分です。よく出る言葉は[英語の画面を読むための単語帳](github-english-ui.md)にまとめています。ほかにも次の方法があります（[GitHubの日本語対応](../../../wiki/tools/github-japanese-support.md)）。

- 公式ドキュメントの日本語版（[GitHub Docs](https://docs.github.com/ja)）を読む。
- ブラウザの翻訳機能を使う。ただしファイル名やコミットメッセージまで翻訳されて分かりにくくなることがあるので、必要なときだけにする。
- 画面の写真や英語の表示をAIに見せて、「これはどういう意味ですか」と聞く。
- VS Codeに日本語言語パックを入れて、VS Codeから操作する（[VS CodeでCopilotを使う準備](vscode-copilot-setup.md)）。

### コミットし忘れたかもしれません

GitHubのブラウザの画面でファイルを編集した場合は、<span class="ui">Commit changes</span>を押した時点でコミットされます。押さずに画面を閉じると、変更は残りません。VS Codeで編集した場合は、コミットするまで変更は自分のパソコンの中にあるだけで、GitHubには届いていません。VS Codeの左側の「ソース管理」の画面に変更の一覧が出ていれば、まだコミットしていない変更があるということです。コミットしたあと、GitHubに送る（プッシュする、または「変更の同期」をする）ことも忘れないようにしましょう。

AIエージェントに作業を頼んだ場合は、エージェントがコミットまでしてくれることが多いですが、念のためリポジトリの履歴（<span class="ui">Commits</span>）で確かめましょう。

### 変更を取り消したい、元に戻したい

どの段階まで進んだかで、戻し方が変わります。

<figure class="fig">
{{svg:faq-undo.svg}}
<figcaption>変更の戻し方は、コミット前、コミット後、マージ後で異なる。どの方法でも履歴は残る。</figcaption>
</figure>

- コミット前：ブラウザで編集中なら<span class="ui">Cancel changes</span>を押す。VS Codeなら「ソース管理」の画面で、その変更を破棄する。
- コミット後：エージェントに「直前のコミットを取り消すコミットを作ってください（git revert）」と頼むのが簡単です。自分で直すなら、履歴から前の版を開き、その内容に書き直してコミットします。
- プルリクエストをマージした後：プルリクエストの画面にある<span class="ui">Revert</span>ボタンで、取り消し用のプルリクエストが作られます（[GitHub Docs](https://docs.github.com/ja/pull-requests/collaborating-with-pull-requests/incorporating-changes-from-a-pull-request/reverting-a-pull-request)）。

「履歴ごと消す」操作（強制的なプッシュなど）は、仲間の作業を壊すことがあるので、意味が分からないうちは使わないでください。エージェントがそうした操作を提案したら、理由を聞いてから判断します。間違えてファイルを消した場合も、履歴に残っているので取り戻せます。

### パスワードやAPIキーをコミットしてしまいました

ファイルから消すだけでは、履歴に残ります。すぐにそのサービスの管理画面でキーを無効にし、新しいキーを作ってください。詳しくは[AIを使うときの倫理とルール](ai-ethics.md)を見てください。

### リポジトリは公開と非公開のどちらにすればよいですか

授業のプロジェクトでの公開範囲は、まだ決まっていません。大学はGitHubとCopilotのプランをMicrosoftと調整しているところで、公開（<span class="ui">Public</span>）と非公開（<span class="ui">Private</span>）のほかに、学内（TCU）だけで共有できる組織内（<span class="ui">Internal</span>）が使えるようになるかもしれません（2026年10月7日時点）。案内があるまでは、練習用のリポジトリは非公開にしておきましょう。公開範囲はあとから変えられますが、どの場合でも、個人情報、APIキー、他人の著作物を置かないようにします（[GitHubとは](github-basics.md)）。

## AIツールについて

### GitHub Copilotの有料版が使えるようになっていません

GitHub Copilotの有料版は、大学の予算で受講生全員に提供されます。提供期間は10月から1月末までです。2026年10月7日時点では、大学がGitHubとCopilotのプランをMicrosoftと調整しているところで、どのプランが提供されるか、どう申し込むかはまだ決まっていません（[GitHub Copilot](../../../wiki/tools/github-copilot.md)）。授業での案内、授業サイト、WebClassの連絡を確かめてください。案内どおりに手続きしても使えない場合は、教員に相談しましょう。

VS Codeで使う場合は、提供を受けたものと同じGitHubアカウントでサインインしているかも確かめます。Copilotでできることは[GitHub Copilotとは](copilot-overview.md)で説明しています。

### どのAIツールを使えばよいですか

この授業では、一つの製品に絞らず、目的に合ったツールを選べるようになることが達成目標の一つです（[この授業で使うAIツール](../../../wiki/tools/ai-tools.md)）。目安は次のとおりです。

- GitHubのリポジトリでの作業、ファイルの作成や整理：GitHub Copilot
- WordやPowerPointなど、Microsoft 365での作業：TCUアカウントで使えるMicrosoft 365 Copilot
- 調べもの、アイデア出し、文章の相談：ChatGPT、Claude、Geminiなど

同じ質問を複数のツールにしてみて、答えを比べるのもよい練習になります。詳しくは[AIツールの選び方](ai-tools-compare.md)を見てください。

### GitHub CopilotとMicrosoft 365 Copilotは同じものですか

名前は似ていますが、別の製品です。GitHub CopilotはGitHubやVS Codeで使い、Microsoft 365 CopilotはTCUアカウントでサインインしてMicrosoft 365の中で使います（[Microsoft 365 Copilot](../../../wiki/tools/microsoft-365-copilot.md)）。

### AIが間違ったことを言います

AIが自信ありげに間違ったことを言うのは、よくあることです。AIは、もっともらしい言葉の続きを予測して文章を作るしくみなので、事実と違う内容や、存在しない文献を作ってしまうことがあります（[生成AIのしくみ](how-llms-work.md)）。

- 大事な事実、数字、固有名詞、文献は、公式のサイトや元の資料で確かめる。
- 「その情報の出典を示してください」と頼み、示された出典を自分で開いて確かめる。
- 資料をAIに渡して、「この資料にもとづいて答えてください」と頼む。
- 別のAIツールにも同じ質問をして、答えを比べる。

確かめ方は[AIの答えを確かめる](checking-ai-output.md)で詳しく説明しています。

### 同じ質問をしても、AIの答えが毎回違います

AIの答えには、ある程度の偶然の要素が入るので、毎回少しずつ違うのがふつうです。気に入った答えが出たら、保存しておきましょう。毎回同じ形で答えてほしいときは、答えの形式（箇条書きで、表で、など）を具体的に指定すると安定します（[AIへの頼み方（プロンプトのコツ）](prompting.md)）。

### AIの利用の上限に達してしまいました

多くのAIサービスには、無料版でも有料版でも、一定の時間内に使える量の上限があります。時間をおいて使うか、ほかのツールに切り替えましょう。大量の作業をまとめて頼むと上限に早く達するので、作業を小分けにするのも手です。

### AIを使ったことは成果物に書くべきですか

書いておくのがよいでしょう。どこでどのようにAIを使ったかを明らかにすることは、透明性と学問的誠実さの面で大切です。書き方の例は[AIを使うときの倫理とルール](ai-ethics.md)にあります。書き方の形式が授業で指定された場合は、それに従ってください。

## このサイトについて

### このサイトとWikiは何が違うのですか

Wikiは、授業の日程、使うツール、学内のサービスなどの事実を、AIエージェントが資料から出典つきでまとめているページ群です。このサイトの解説ページは、Wikiの事実をもとに、考え方や使い方を詳しく説明するものです（[このサイトの使い方](about-this-site.md)）。言葉の意味を調べたいときは[用語集](glossary.md)が便利です。

### 書いてあることが古い、または間違っているようです

授業の情報は、学期の途中で変わることがあります。最新の情報は授業での案内と授業サイトで確かめ、このサイトやWikiの誤りに気づいたら教員に知らせてください。
