ターミナルは、文字で命令を打ち込んでパソコンを動かす画面です。マウスで操作する画面（GUI）と違い、命令を一行書くと、その結果が文字で返ってきます。AIのエージェントは、ファイルの操作やGitの操作をこの画面で行うことが多くあります（[AIエージェントとは](ai-agents.md)）。

このページの目的は、ターミナルを使いこなすことではありません。エージェントが「この命令を実行してよいですか」と聞いてきたときに、何をする命令なのかを読み取り、許可するか断るかを判断できるようになることです。

## ターミナルを開く

- Mac：アプリの<span class="ui">Terminal</span>を開く。
- Windows：<span class="ui">Windows Terminal</span>または<span class="ui">PowerShell</span>を開く。
- VS Code：メニューの<span class="ui">Terminal</span>から<span class="ui">New Terminal</span>を選ぶと、画面の下に開く。開いているフォルダーが最初から選ばれているので、初めてなら、ここがいちばん安全です。

画面の名前や並びはOSやバージョンで違います。開き方が分からないときは、担当者に聞いてください。

命令は、たいてい「道具の名前」「やること」「オプション」「対象」を空白で区切って並べます。Gitなら、`git`が道具の名前、`commit`がやることです。`-m`のようにハイフンで始まる部分がオプションで、命令の動き方を変えます。

ターミナルは、いま「どのフォルダーにいるか」を持っています。同じ命令でも、いるフォルダーが違えば、対象になるファイルが変わります。

## まず覚える命令

次の命令は、中のものを見るだけで、何も壊しません。エージェントが最初に打つことも多い命令です。

| 命令 | 何をするか |
| :---- | :---- |
| `pwd` | いま、どのフォルダーにいるかを表示する |
| `ls` | いるフォルダーの中のファイルを一覧にする |
| `cd フォルダー名` | そのフォルダーに移る。`cd ..`で一つ上に戻る |
| `git status` | 変更したファイルと、Gitでの状態を表示する |
| `git log` | これまでのコミット（変更の記録）を表示する |

`pwd`と`ls`はMacとPowerShellのどちらでも使えます。PowerShellでは、ほかの書き方の命令もありますが、エージェントが打つ命令はOSに合わせて変わるので、見慣れない形でも心配しすぎなくて構いません。

## 変更を起こす命令

次の命令は、ファイルやGitの状態を変えます。意味を知っておくと、許可するときに落ち着いて判断できます。

| 命令 | 何をするか |
| :---- | :---- |
| `git add` | コミットに入れる変更を選ぶ |
| `git commit -m "説明"` | 選んだ変更を、説明を付けて記録する |
| `git push` | 手元の記録をGitHubに送る |
| `git pull` | GitHubの新しい記録を手元に取り込む |
| `git clone URL` | GitHubのリポジトリを手元にコピーする |
| `mkdir 名前` | 新しいフォルダーを作る |

Gitの用語は[GitHubとは](github-basics.md)と[用語集](glossary.md)で説明しています。

## 許可の前に確かめる命令

次のような命令が出てきたら、実行を許可する前に、必ず止まって考えてください。

<div class="box danger" markdown="1">
<p class="box-title">止まって確かめる</p>

- `rm`、`rm -r`、`del`、`rmdir`：ファイルやフォルダーを消す。ゴミ箱を通らず、戻せないことが多い。
- `git push --force`（または`-f`）：GitHubの履歴を強制的に上書きする。
- `git reset --hard`：まだ記録していない変更を捨てる。
- `sudo`：管理者の権限で実行する。
- `curl ... | sh`のように、ネットからのものをそのまま実行する形。
- パスワードやトークンを命令の中に書く形。

</div>

意味が分からないときは、許可せずに「この命令は何をしますか。消えるものはありますか」とエージェントに聞いてください。説明を聞いても納得できなければ、断ってかまいません。断っても、エージェントは別の方法を探します。

## 自分で打つときの約束

- 見ただけの命令は、そのまま打たない。意味が分かってから打つ。
- 打つ前に、`pwd`でいる場所を確かめる。思っていないフォルダーで消す命令を打つ事故を防げる。
- エラーが出たら、表示された文面をそのままAIに貼って聞く。ただし、パスワードなど他人に見せてはいけないものが入っていないか、先に確かめる（[AIを使うときの倫理とルール](ai-ethics.md)）。
- 大事な作業の前には、Gitでコミットしておく。失敗しても、記録から戻せる。

<div class="box try" markdown="1">
<p class="box-title">やってみよう</p>

VS Codeでテスト用のフォルダーを開き、ターミナルを開いて、`pwd`、`ls`、`git status`を順に打ってみましょう。結果が何を表しているかを、AIに「この出力を初心者向けに説明して」と聞いて確かめます。

</div>
