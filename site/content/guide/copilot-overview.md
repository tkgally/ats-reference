## GitHub Copilotは「GitHubに住んでいるAIの相棒」

GitHub Copilot（ギットハブ・コパイロット）は、GitHubが提供するAIアシスタントです。Copilotは「副操縦士」という意味で、操縦するのはあくまで人間、AIは横で手伝う役だ、という考え方が名前に込められています。もともとはプログラムを書く人のために、書きかけのコードの続きを提案する道具として始まりましたが、2026年10月時点では、質問に答えるチャット、ファイルの書き換え、作業を自分で進めるエージェントまで、できることが大きく広がっています。

プログラムを書かない人にも役に立ちます。この授業では、たとえば次のような使い方が考えられます。

- Markdownで書いた企画書や調査メモを、読みやすく整えてもらう。
- リポジトリの中の資料を読ませて、「この資料の要点は何か」と質問する。
- 知識ベース（Wiki）に新しい資料を取り込む作業を、エージェントに任せる。
- GitHubの英語の画面で分からない言葉や操作を、日本語で聞く。

この授業では、大学の予算で受講生全員にCopilotの有料版が提供されます。提供期間は10月から1月末までです（2026年10月7日時点、[GitHub Copilot](../../../wiki/tools/github-copilot.md)）。

## Copilotを使える場所

Copilotは一つのアプリではなく、GitHubのアカウントにひもづいたサービスです。同じアカウントでサインインすれば、いくつかの場所から同じCopilotを使えます。

<figure class="fig">
{{svg:copilot-overview-where.svg}}
<figcaption>Copilotは自分のGitHubアカウントにひもづいている。ブラウザ、エディター、スマートフォン、ターミナルのどこからでも使える。</figcaption>
</figure>

| 場所 | どう使うか | この授業での使いどころ |
| :---- | :---- | :---- |
| github.com（ブラウザ） | 画面のCopilotのアイコンからチャットを開く。リポジトリについて質問したり、クラウドエージェントに作業を頼んだりする。 | パソコンに何も入れずにすぐ使える。リポジトリの中身についての質問や、エージェントへの依頼に。 |
| VS Code（エディター） | パソコンに入れたVS Codeの中で、補完、チャット、エージェントを使う。 | 日本語の画面で作業でき、ファイルを書きながら相談できる。いちばん多く使う場所になる。 |
| GitHub Mobile（スマートフォン） | GitHubの公式アプリからチャットで質問する。 | 移動中に質問したり、エージェントの作業の進み具合を確かめたりする。 |
| ターミナル（Copilot CLI） | 文字で命令を打ち込む画面から、Copilotに作業を頼む。 | 慣れてきた人向け。授業で必須ではない。 |

VS Codeの準備のしかたは[VS CodeでCopilotを使う準備](vscode-copilot-setup.md)で説明します。

## 使い方は大きく5種類

Copilotの使い方は、AIにどこまで任せるかによって、大きく5種類に分けられます。左ほどAIの役目が小さく、右ほどAIが自分で考えて進める範囲が広くなります。

<figure class="fig">
{{svg:copilot-overview-spectrum.svg}}
<figcaption>補完からクラウドエージェントへ進むほど、AIに任せる範囲が広がる。そのぶん、人が結果を確かめる責任も大きくなる。</figcaption>
</figure>

- 補完（コード補完、インライン提案）：エディターで文章やコードを書いていると、続きを薄い文字で提案してくれる。<kbd>Tab</kbd>キーで受け入れ、無視すればそのまま書き続けられる。
- チャット（Ask）：質問すると答えてくれる。開いているファイルやリポジトリを踏まえて答えられるのが、ふつうのチャットAIとの違い。ファイルは書き換えない。
- 編集：「この段落をもっと短くして」のように頼むと、指定した箇所を書き換える案を出す。採用するかどうかは自分で決める。
- エージェント（エージェントモード）：「この資料を読んでWikiに取り込んで」のような目標を伝えると、AIが自分で手順を考え、複数のファイルを読み書きし、必要なら命令を実行しながら作業を進める。VS Codeなどエディターの中で動く。
- クラウドエージェント：GitHubのサーバーの上で動くエージェント。作業を頼むと、Copilotがブランチを作って作業し、終わったらプルリクエストを出してくれる。人はその内容を確かめてマージする。2026年10月時点の公式の名前は「Copilot cloud agent」で、以前は「Copilot coding agent」と呼ばれていた。

最初は、チャットで質問するところから始めるのがおすすめです。慣れてきたら、エディターのエージェント、GitHubのクラウドエージェントへと任せる範囲を広げていきましょう。エージェントへの頼み方は[Copilotのエージェントに作業を頼む](copilot-agent.md)で、エージェントという考え方そのものは[AIエージェントとは](ai-agents.md)で説明します。

<div class="box note" markdown="1">
<p class="box-title">補足</p>

製品の画面では、使い方の種類が「モード」や「エージェント」の名前で選べるようになっています。VS Codeでは、2026年10月時点で<span class="ui">Ask</span>、<span class="ui">Agent</span>、<span class="ui">Plan</span>などが選べます（以前は<span class="ui">Edit</span>という種類もありました）。名前や分け方は頻繁に変わるので、画面の表示が説明と違っても、上の5種類のどれに当たるかを考えれば迷いにくくなります。

</div>

## プランと、この授業で使える版

Copilotには、無料のものから企業向けのものまで、いくつかのプランがあります。2026年10月時点の公式の案内（[Plans for GitHub Copilot](https://docs.github.com/en/copilot/get-started/plans)、2026年10月7日に確認）では、次のプランが挙げられています。正式な名前は「Copilot Free」「Copilot Pro」のように、どれも「Copilot」から始まります。Studentは、GitHub Education（学生向けの支援の制度）で学生であることを認証された人が対象です。

| プラン | 対象 | 料金（2026年10月時点） |
| :---- | :---- | :---- |
| Free | だれでも | 無料。使える機能と量に制限がある。 |
| Student | 認証された学生 | 無料。 |
| Pro | 個人 | 月10ドル |
| Pro+ | 個人 | 月39ドル |
| Max | 個人 | 月100ドル |
| Business | 組織 | 1人あたり月19ドル |
| Enterprise | 組織 | 1人あたり月39ドル |

プランによって、使えるAIモデル、使える量、クラウドエージェントが使えるかどうかなどが違います。たとえば2026年10月時点では、Copilot Freeではクラウドエージェントが使えず、モデルは自動選択（Auto）のみとされています。

この授業では、大学の予算で受講生全員に有料版が提供されます。大学はGitHubとCopilotのプランをMicrosoftと調整しているところで、どのプランに当たるのか、どう申し込むのかは、2026年10月7日時点ではまだ決まっていません。詳しいことは授業やWebClassで案内される予定です。最新の情報は[GitHub Copilot](../../../wiki/tools/github-copilot.md)のWikiページで確かめてください。

<div class="box warn" markdown="1">
<p class="box-title">注意</p>

授業での案内がある前に、自分でお金を払って有料プランを申し込む必要はありません。授業で提供される版が使えるようになるまでは、無料のCopilot Freeで試してみるとよいでしょう。

</div>

## Microsoft 365 Copilotとの違い

名前がよく似ていますが、Microsoft 365 Copilotは別の製品です。東京都市大学の受講生は、TCUアカウントでMicrosoft 365 Copilotも使えます。

| | GitHub Copilot | Microsoft 365 Copilot |
| :---- | :---- | :---- |
| 提供元 | GitHub | Microsoft |
| 使う場所 | github.com、VS Code、GitHub Mobileなど | Microsoft 365（Word、Excel、Teams、ブラウザなど） |
| サインイン | 自分のGitHubアカウント | TCUアカウント |
| 得意なこと | リポジトリのファイルを読み書きし、作業を進めること | メールや文書、表計算など、Officeでの仕事を手伝うこと |
| この授業での入手 | 大学の予算で有料版が提供される | TCUアカウントで利用できる |

GitHubはMicrosoftの子会社なので、どちらにも「Copilot」という名前が付いていますが、アカウントも契約も別です。GitHubのリポジトリでの作業にはGitHub Copilotを使います。詳しくは[Microsoft 365 Copilot](../../../wiki/tools/microsoft-365-copilot.md)のWikiページを見てください。

## 日本語で使う

Copilotの画面の表示は、github.comでは英語です。それでも、日本語で質問すれば日本語で答えてくれます。VS Codeに日本語言語パックを入れれば、エディターのメニューも日本語になり、日本語でいちばん作業しやすい環境になります（[GitHubの日本語対応](../../../wiki/tools/github-japanese-support.md)、[VS Code](../../../wiki/tools/vs-code.md)）。

日本語で使うときのコツをいくつか挙げます。

- ときどき英語で答えが返ってくることがある。そのときは「日本語で答えてください」と一言添える。
- AIが書いたコミットメッセージやファイルが英語になることがある。日本語にしたいときは、頼むときに「コミットメッセージは日本語で」と書く。
- リポジトリに指示ファイル（この授業では`AGENTS.md`）を置き、「日本語で書く」「段落の途中で改行しない」などの約束事を書いておくと、毎回言わなくても守ってもらえる（[Copilotのエージェントに作業を頼む](copilot-agent.md)）。

## AIモデルの選択と「Auto」

Copilotの中では、OpenAI、Anthropic、Googleなど、いくつかの会社の大規模言語モデル（LLM）が使われています。チャットの入力欄の近くにあるモデルの選択欄で、どのモデルを使うかを選べる場合があります。モデルによって、速さ、得意なこと、使える量の減り方が違います。

選択欄で<span class="ui">Auto</span>を選ぶと、Copilotが作業の内容や混み具合に応じて、モデルを自動で選びます。2026年10月時点の公式の案内では、Copilot FreeとCopilot Studentは自動選択（Auto）のみとされています。この授業で提供される版でモデルを自分で選べるかどうかは、まだ分かっていません（要確認）。

モデルの名前と顔ぶれは、数か月単位で入れ替わります。特定のモデル名を覚えるより、「迷ったらAutoにしておく」「うまくいかないときは別のモデルを試す」くらいの気持ちで使えば十分です。モデルのしくみは[大規模言語モデルのしくみ](how-llms-work.md)で説明します。

## 使える量には上限がある

Copilotは使い放題ではなく、プランごとに1か月に使える量が決まっています。2026年6月1日から、使った量は「GitHub AI Credits」（AIクレジット）という単位で数えられるようになりました。おおまかには、次のように考えるとよいでしょう。

- AIに何かを頼むたびに、クレジットが少しずつ減る。
- 大きなモデルを使うときや、エージェントが長い作業をするときほど、多く減る。
- 月の上限に近づくと、使えるモデルや機能が制限されることがある。翌月になると、また使えるようになる。

どれくらい使ったかは、GitHubの設定画面などで確かめられます（画面の場所は変わることがあります）。量の決まり方の詳細は、公式の[Plans for GitHub Copilot](https://docs.github.com/en/copilot/get-started/plans)を見てください。

<div class="box tip" markdown="1">
<p class="box-title">ポイント</p>

使える量を大切に使うには、頼む作業を小さく区切り、頼む内容を最初からはっきり書くのが効果的です。あいまいに頼んでやり直しを繰り返すと、そのぶん量が減ります。頼み方のコツは[AIへの頼み方（プロンプト）](prompting.md)にまとめています。

</div>

## 気をつけること

Copilotはとても便利ですが、間違えることもあります。もっともらしい説明が事実と違っていたり、頼んでいないファイルまで書き換えたりすることがあります。AIが出した結果は、必ず自分の目で確かめてから使いましょう（[AIの出力を確かめる](checking-ai-output.md)）。

また、Copilotに渡した内容は、AIのサービスに送られて処理されます。他人の個人情報、パスワード、公開してはいけない資料は、Copilotに読ませたり、リポジトリに置いたりしないでください（[AIを使うときの倫理とルール](ai-ethics.md)）。

<div class="box try" markdown="1">
<p class="box-title">やってみよう</p>

github.comにサインインし、このガイドのリポジトリ（または自分のリポジトリ）を開いて、Copilotのチャットに「このリポジトリには何が入っていますか。日本語で、初心者向けに説明してください」と聞いてみましょう。答えと実際のファイルを見比べて、合っているかどうかを確かめてみてください。

</div>
