アンケートの結果、天気の記録、学内の施設の利用状況など、数字や項目が並んだ「データ」を使うプロジェクトは多くあります。AIは、集計の手順を考えたり、グラフを描くプログラムを書いたりするのが得意です。一方で、データの中身を取り違えたり、もっともらしい数字を作り出したりすることもあります（[AIの答えを確かめる](checking-ai-output.md)）。このページでは、データを扱うときの進め方と、AIに頼むときの約束を説明します。

いきなりAIに「このデータを分析して」と頼むのは、おすすめしません。何を知りたいのかが決まっていないと、AIはそれらしい集計を並べるだけになり、プロジェクトの問いに答えているのかが分からなくなります。最初に問いを一文で書いておきます。たとえば「学食が混む時間帯は、何時から何時か」のようなものです。

## データの形：表とCSV

データは、行と列でできた表の形にそろえると扱いやすくなります。1行が1件の記録、1列が1つの項目です。

| 日付 | 時間帯 | 人数 |
| :---- | :---- | :---- |
| 10月13日 | 12時 | 85 |
| 10月13日 | 13時 | 40 |
| 10月14日 | 12時 | 92 |

表計算ソフト（ExcelやGoogleスプレッドシート）の表は、CSVという文字だけの形式で保存できます。CSVは、項目をカンマで区切って1行に1件ずつ書いた、ただの文字のファイルです。上の表なら、次のようになります。

```
日付,時間帯,人数
10月13日,12時,85
10月13日,13時,40
10月14日,12時,92
```

CSVはAIにも読ませやすく、GitHubのリポジトリに置いて変更の履歴を残すこともできます。ただし、文字化けすることがあります。日本語のCSVをExcelで開いて文字化けしたときは、文字コード（UTF-8かShift_JISか）が合っていないことが多い、と覚えておくと、AIに相談するときに役立ちます。

<div class="box note" markdown="1">
<p class="box-title">データの出どころと使ってよいか</p>

自分で集めたアンケートなら、答えた人が特定されないか、集める前に説明して同意をもらったかを確かめます。他人が公開しているデータを使うときは、出どころ（誰が、いつ、どこで公表したか）と、利用の条件を記録します。氏名や学籍番号などが入ったデータは、AIのサービスに貼り付けません（[AIを使うときの倫理とルール](ai-ethics.md)）。

</div>

## 使う前に点検する

AIに渡す前に、自分の目で表を眺めます。見るのは次の点です。

- 空欄はないか。あるなら、記録し忘れか、「なし」の意味か。
- 単位はそろっているか。「分」と「時間」、「円」と「千円」が混ざっていないか。
- 同じものが別の書き方になっていないか。「学食」と「食堂」、全角と半角の数字など。
- 極端に大きい値や小さい値はないか。入力の間違いか、本当の値か。
- 何件あるか。数件のデータでは、傾向とは言えない。

見つけた問題は、勝手に直さずに記録します。「3件の空欄は除いて集計した」のように、どう扱ったかを後で言えるようにするためです。

## AIに頼む

データの点検が済んだら、AIに頼みます。頼み方の基本は[AIへの頼み方](prompting.md)と同じですが、データでは次の三つを必ず伝えます。

1. 問い：何を知りたいのか。
2. 表の説明：各列が何を表し、単位は何か。
3. 出してほしい形：平均を表にする、棒グラフにする、など。

「このデータを分析して」

表計算ソフトを使うなら、「この列の平均を出す式を教えて」のように、手順や式を教えてもらう頼み方もできます。式の意味が分かるので、後で自分で直せます。

### 数字の計算はAIに任せきらない

文章を作るAIは、計算を間違えることがあります。特に、データを文章として貼り付けて「合計は？」と聞くと、それらしい誤った数字を答えることがあります。次のようにすると安全です。

- 計算は、表計算ソフトの式やプログラムにさせる。AIには、その式やプログラムを書かせる。
- Copilotのエージェントのように、プログラムを実際に動かせる道具を使うと、計算を道具が行うので、数字の信頼性が上がる（[AIエージェントとは](ai-agents.md)）。
- 出た数字は、後で述べる方法で必ず確かめる。

## グラフの選び方と見せ方

何を見せたいかで、グラフの種類を選びます。

| 見せたいこと | 向いているグラフ |
| :---- | :---- |
| 項目どうしの大きさの比べ | 棒グラフ |
| 時間による変化 | 折れ線グラフ |
| 全体に対する割合（項目が少ないとき） | 円グラフまたは積み上げの棒グラフ |
| 2つの量の関係 | 散布図 |

AIにグラフを描かせるときは、種類を指定し、軸の名前と単位、題名を付けるように頼みます。次の図のように、縦軸の始まりを変えるだけで、同じ数字でも差の印象が大きく変わります。棒グラフの縦軸は、0から始めるのが原則です。

## 結果を確かめる

AIが出した集計やグラフは、次の方法で確かめます。

- 元の表の一部を、自分で電卓や表計算ソフトで計算して、AIの数字と合うか見る。
- 件数を確かめる。集計の対象になった件数が、元の件数と合うか。AIが一部の行を落としていることがある。
- グラフの数字を、元の表の数字と見比べる。
- 結論が、データから言える範囲を超えていないか。3日分の記録から「いつも混む」とは言えない。「原因」も同じで、2つの量が一緒に動いていても、一方が他方の原因とは限らない。

<div class="box try" markdown="1">
<p class="box-title">やってみよう</p>

10行ほどの小さな表を自分で作り、AIに「平均と最大値を求めて」と頼みます。次に、答えを自分で計算して見比べます。合っていれば、AIにグラフの描き方も頼んでみましょう。AIが計算の過程を説明したら、その通りに元の表を追えるかも確かめます。

</div>

## 記録を残す

データを扱うプロジェクトは、後から「この数字はどうやって出したのか」と聞かれやすい分野です。次のことをプロジェクトの記録（[プロジェクトの進め方](project-workflow.md)）に残します。

- データの出どころと、集めた日。
- 点検で見つけた問題と、その扱い。
- AIに頼んだ内容と、AIが書いた式やプログラム。
- 確かめた方法と、その結果。

[成果を発表する](presenting.md)ときにも、この記録がそのまま材料になります。
