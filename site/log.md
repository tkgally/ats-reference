# サイトの作業記録

解説サイト「ATSガイド」の作業を記録するファイルです。上の「次の作業の候補」はその時点の状態に書き換えてよく、下の「作業記録」は追記のみとします。Wikiの作業をするエージェントも、解説ページについて気づいたことを「次の作業の候補」に書き足してかまいません。

## 次の作業の候補

### 新しい解説ページ

- 成果の発表：スライドの作り方、AIでの下書き、発表の練習、デモの見せ方（授業の後半に向けて）。
- チームでの進め方：役割分担、GitHubでの共同作業の決まり、Issuesの使い方、話し合いの記録。
- Microsoft 365 Copilotの使い方：TCUアカウントでのサインイン、Word・PowerPoint・Teamsでの使い方（学内の案内が資料として加わったら）。
- 画像・音声・動画を生成するAI：種類、使い方、著作権と表示の注意。
- AIを使った調べもの：検索との違い、deep research型の機能、文献の探し方と確かめ方。
- AIと一緒に文章を書く：構成、下書き、推敲、自分の言葉で書くことの意味。
- コマンドライン（ターミナル）入門：エージェントが打つ命令を読めるようになるための最小限の知識。
- データを扱うプロジェクト：表計算、CSV、グラフ化をAIに頼む方法。

### 既存のページの改良

- GitHubの画面の操作を見せる短い動画やアニメーション（模式図で）を増やす。
- 体験コーナー（`site/static/site.js`の`demos`）を増やす。候補：プロンプトの改善前後の比較、コミットとブランチの操作を試せる小さなシミュレーター、AIの答えの誤り（ハルシネーション）を見つけるクイズ、コンテキストウィンドウから古い会話があふれる様子、「AIに貼り付ける前の確認」（Q1〜Q4に答えると判断が出る）、Markdownを書くと表示と規則違反（`**`の誤用、段落内の改行）が分かるプレビュー、エージェントの「計画→道具→観察」を一歩ずつ見せる体験。
- 「書き方／表示」を並べる専用の部品と、チェックリスト用の書式をCSSに加える。
- GitHubとVS Codeの画面の表記のうち、記憶にもとづいて書いたもの（二要素認証の設定の場所、コンフリクト解消の画面、VS Codeのソース管理の表記など）を、公式のドキュメントで確かめる。
- 用語集に、各解説ページで新しく出てきた言葉を足す。
- 授業の各回の内容が分かってきたら、ホームに「今週の授業に関係するページ」の欄を作る。

### Wikiとの連携

- 授業サイトのログのページ、Copilotの配布方法の案内などが`raw/`に加わったら、関係する解説ページ（GitHub Copilotとは、よくある質問など）の記述を直す。
