# GitHub Copilotデスクトップアプリ

自分のパソコンにインストールして、リポジトリの作業をCopilotに頼むためのアプリ、GitHub Copilotデスクトップアプリについてのページです。

## この授業での位置づけ

この授業では、LLMを使うことと、GitHubのリポジトリで作業することの両方を、おもにこのアプリで行います（担当教員の方針、2026年10月13日）。ほかのAIツール（ChatGPT、Claude、Geminiなど）も、プロジェクトに合わせて選んで使えます（[この授業で使うAIツール](ai-tools.md)）。

## どんなアプリか

公式ドキュメント「GitHub Copilot アプリ」によれば、このアプリはすべてのCopilotプランで使え、macOS、Linux、Windowsに対応しています。セッションごとに専用のブランチを作って作業し、セッションのモードは、対話型（一緒に進める）、プラン（計画を立てて承認する）、Autopilot（完全に自律的）の三つです（2026年10月13日に確認されたもの。[資料：Copilotデスクトップアプリを使い始めるためのガイド](../sources/20261013-GitHub-and-Copilot-information.md)の記述による。この文書の作成者が公式ドキュメントを見た内容で、エージェント自身はまだ公式ページを確かめていない）。ブランチについては[GitHub flow](../concepts/github-flow.md)を参照してください。

Copilot BusinessとCopilot Enterpriseでは、組織の「GitHub Copilot app」ポリシーが有効である必要があります。このポリシーは既定で有効ですが、大学の組織で無効にされていないかは分かっていません（要確認）。

## 使い始めるまでの流れ（2026年10月13日時点の見取り図）

1. 準備：パソコン、ネット接続、二要素認証用のスマートフォン、配られたアカウントの情報。
2. 配られたGitHubアカウントで、ブラウザから初めてログインする。
3. [二要素認証](../concepts/two-factor-authentication.md)を設定する。
4. `https://github.com/settings/copilot`でCopilotの利用権が付いているかを確かめる。
5. アプリを入手してインストールし、同じアカウントでサインインする。
6. 練習用の[リポジトリ](../concepts/repository.md)を作る。公開範囲はまずPrivate。
7. アプリでリポジトリを開き、日本語でCopilotに作業を頼む。最初のモードは対話型かプランにする。

これは一般的なGitHubとCopilotの流れにもとづく見取り図で、大学の設定によって画面や順番が変わりえます。IT担当者の説明と食い違ったら、IT担当者の説明を優先します（同資料）。画面ごとの具体的な手順は、まだ確かめられていません。

## つまずきやすい点

- アカウントの種類：大学が配ったアカウントが、大学が管理するアカウント（EMU）か、組織に参加させる個人アカウントかで、ログイン方法や、公開リポジトリを作れるかなどが変わりうる。どちらかは分かっていません（要確認）。
- 別のアカウントでのサインイン：個人のアカウントがブラウザにログインしたままだと、アプリに授業用ではないアカウントがつながることがある。授業用のアカウントだけにするか、プライベートウィンドウを使う。
- 利用権がない：Copilotの利用権がないアカウントでは、機能が使えないか、無料の範囲に制限される。
- 学内ネットワーク：ダウンロードや認証の通信が制限されている可能性がある。つながらないときはスマートフォンのテザリングを試す（いずれも要確認）。[学内Wi-Fi](../campus/campus-wifi.md)も参照。
- 保存先：OneDriveなど自動で同期されるフォルダーの中は避ける。

## 安全のための約束

- 学籍番号、成績、他人の個人情報、パスワード、APIキーを、リポジトリやCopilotへの入力に書かない。
- 非公開のリポジトリでも、共同作業者には見える。招待は仲間と教員だけにする。
- Copilotが許可を求めたら、内容を読んでから許可する。分からなければ許可しない。
- Autopilotは慣れるまで使わない。

## 未解決の点（IT担当者への質問）

資料に挙げられた質問のうち、特に授業の進行に関わるもの。

- 配られたアカウントの種類、ユーザー名の形式、ログインのURL。
- 二要素認証の方式と、スマートフォンがない場合の代替。
- 全員にCopilotの利用権が割り当て済みか。どのプランか。
- 大学の組織で「GitHub Copilot app」のポリシーが有効か。
- リポジトリを作る場所と選べる公開範囲、教員が閲覧する方法。
- 学内ネットワークで通信が通るか。追加のソフト（Gitなど）が必要か。

回答が分かったら、このページとほかの関連ページを更新します（資料の文面からは、2026年10月14日の授業でIT担当者の説明がある予定と読み取れる）。
