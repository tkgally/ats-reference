# GitHubの日本語対応

GitHubの画面が英語であることと、それを日本語で補う方法をまとめたページです。

## 現状（2026年10月時点）

GitHubのウェブサイト（github.com）には公式の日本語インターフェースがなく、画面は英語で表示されます。

## 日本語で使える部分と補う方法

- 公式ドキュメント：[GitHub Docs](https://docs.github.com/ja)には日本語版がある。GitHubのサポートポータルも日本語に対応している。
- ブラウザの翻訳機能：ChromeやEdgeの翻訳機能を使えば、メニューや設定画面を日本語で表示できる。ただしファイル名、コード、コミットメッセージまで翻訳されて分かりにくくなることがあるので、必要なときだけ使うのがよい。
- AIアシスタント：[GitHub Copilot](github-copilot.md)は画面こそ英語だが、日本語で質問すれば日本語で答える。ほかのAIエージェントも同様。
- VS Code：Microsoft公式の日本語言語パックを入れれば、エディターの画面を日本語にできる。VS CodeでCopilotを使う場合、最も日本語で作業しやすい環境になる（[VS Code](vs-code.md)）。

## この授業での考え方

英語の画面は、リポジトリの作成、ファイルと履歴の確認、招待の承諾など、必要な操作に絞って覚えれば十分です。それ以外の作業の多くは、AIエージェントに日本語で頼んで進められます。
