# ChatGPT、Claude、Gemini

授業でプロジェクトに合わせて選んで使う汎用のAIチャットサービス、ChatGPT、Claude、Geminiについてのページです。

## この授業での位置づけ

背景資料では、GitHub CopilotとMicrosoft 365 Copilotのほかに、ChatGPT、Claude、GeminiなどのAIツールを「プロジェクトに合わせて選ぶ」とされています（[資料：授業の背景情報](../sources/ats-class-background.md)）。シラバスの達成目標の一つは、複数のAIツールの特性を理解して、プロジェクトに適したものを選べるようになることです（[達成目標](../course/learning-goals.md)）。大学としてこれらのサービスを提供するのか、費用をどう扱うのかは、資料からは分かりません（要確認）。

## 三つのサービス

| サービス | 提供する会社 | 料金の概要（2026年10月7日時点） |
| :---- | :---- | :---- |
| ChatGPT | OpenAI | 無料プランと、月額およそ20ドルの有料プラン、さらに上位のプラン |
| Claude | Anthropic | 無料プランと、月額およそ20ドルの有料プラン、さらに上位のプラン |
| Gemini | Google | 無料プランと、月額およそ20ドルの有料プラン、さらに上位のプラン |

料金や内容は変わりやすいので、使う前に公式のページで確かめてください（[資料：ChatGPT、Claude、Geminiの料金とデータの設定](../sources/web-ai-chat-services.md)）。どれも、文章の作成や要約、調べもの、アイデア出し、プログラムの作成などに使えます。それぞれの得意なことはモデルの更新で変わるので、同じ頼みごとを二つ以上のサービスで試して比べるのがよいとされます（資料外の補足）。

## データの設定

三つのサービスとも、会話の内容をモデルの改良（学習）に使うかどうかを設定で選べます。設定の場所は[資料：ChatGPT、Claude、Geminiの料金とデータの設定](../sources/web-ai-chat-services.md)にまとめています。他人の個人情報や、公開してはいけない資料は、設定にかかわらず入力しないのが安全です（[AI利用の倫理](../concepts/ai-ethics.md)）。
