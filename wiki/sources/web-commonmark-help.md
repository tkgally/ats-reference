# 資料：Markdown Reference（CommonMark）

Markdownの標準仕様を整備するCommonMarkのサイトにある、書き方の早見表の要約です（2026年10月9日に確認）。

## 資料の情報

- 題名：Markdown Reference
- URL：[https://commonmark.org/help/](https://commonmark.org/help/)
- 発行者：CommonMark
- 確認した日：2026年10月9日
- 種類：ウェブ上の資料（エージェントが調べたもの。`raw/`の資料ではない）

## 内容の要約

- Markdownは、フォントの大きさや色の変更のような凝ったことはせず、キーボードの記号だけで最低限の書式を付ける方法。どの端末でもきれいに表示される。
- 主な書き方：斜体は`*`または`_`で囲む、太字は`**`または`__`で囲む、見出しは行頭の`#`（個数で段階）、リンクは`[表示名](URL)`、画像は`![説明](URL)`、引用は行頭の`>`、箇条書きは行頭の`*`または`-`、番号付きの箇条書きは`1.`、水平線は`---`、コードは`` ` ``で囲む、コードブロックは`` ``` ``で囲む（または4文字分字下げ）。
- 詳しい規則は公式の仕様（CommonMark spec）にあり、10分で試せる対話式のチュートリアルもある。
