# 資料：学生向けのGitHub Copilot

学生が無料でGitHub Copilotを使うしくみ（GitHub Education）についての、GitHubの公式ドキュメントとお知らせの要約です（2026年10月7日に確認）。

## 資料の情報

- 題名：Access GitHub Copilot for free as a student（GitHub Docs）
- URL：[https://docs.github.com/en/copilot/how-tos/copilot-on-github/set-up-copilot/enable-copilot/set-up-for-students](https://docs.github.com/en/copilot/how-tos/copilot-on-github/set-up-copilot/enable-copilot/set-up-for-students)
- 関連するお知らせ：Important Updates to GitHub Copilot for Students（GitHub Community、2026年3月、[https://github.com/orgs/community/discussions/189268](https://github.com/orgs/community/discussions/189268)）
- 発行者：GitHub
- 確認した日：2026年10月7日
- 種類：ウェブ上の資料（エージェントが調べたもの。`raw/`の資料ではない）

## 内容の要約

- GitHub Educationで学生であることが認証されると、GitHub Copilotを無料で使える。認証は、GitHubの設定画面の教育特典（Education benefits）のページから申し込む。
- 認証されてから使えるようになるまで、数日かかることがある。その間に有料版の購入画面が表示されても、購入する必要はない。
- 学生の資格は毎月確かめ直される。
- 2026年3月12日から、学生の無料利用は「GitHub Copilot Student」というプランで扱われるようになった。このとき、一部の高性能なモデルを手動で選ぶことができなくなり、モデルを自動で選ぶ方式（Auto）が中心になったと報じられている。

## この授業との関係

「AIとの探検ゼミナール」では、大学の予算で受講生全員にGitHub Copilotの有料版が提供されます（[資料：授業の背景情報](ats-class-background.md)）。それがGitHub Educationの学生向けプランとどう関係するのか（別のプランなのか、学生向けプランに加えて提供されるのか）は、2026年10月7日時点で分かっていません。
