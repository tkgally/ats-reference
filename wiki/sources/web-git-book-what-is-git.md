## 内容の要約

- Gitは、データを「ファイルごとの変更の一覧」ではなく、プロジェクト全体の「スナップショット（ある時点の写真）の連なり」として扱う。コミットのたびに、その時点の全ファイルの状態を記録する。変わっていないファイルは、前の同じファイルへの参照だけを保存する。
- ほとんどの操作は手元のコンピューターだけで完結する。履歴の全体が手元のディスクにあるので、履歴の閲覧などがほぼ一瞬でできる。
- ネットワークにつながっていなくても、コミットまでの作業ができる。サーバーにつながったときにまとめて送ればよい。
