# 資料：GitHubのプランとPrivateリポジトリでのGitHub Pages（GitHub Docs）

GitHubの公式ドキュメント「GitHub's plans」にある、プランごとの機能の違いのうち、GitHub PagesをPrivateのリポジトリで使えるかについての要約です（2026年10月24日に確認）。

## 資料の情報

- GitHub's plans：[https://docs.github.com/en/get-started/learning-about-github/githubs-plans](https://docs.github.com/en/get-started/learning-about-github/githubs-plans)
- What is GitHub Pages?：[https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)
- 発行者：GitHub
- 確認した日：2026年10月24日
- 種類：ウェブ上の資料（エージェントが調べたもの。`raw/`の資料ではない）

## 内容の要約

- 個人アカウントのFree：GitHub PagesはPublicのリポジトリでだけ使える。
- 個人アカウントのPro：Privateのリポジトリの機能の一覧にPagesが載るが、注記に「GitHub Pagesのサイトを非公開で公開するには、組織のアカウントが必要」とある。個人アカウントでは非公開にできない。
- 組織のTeam：Privateのリポジトリの機能の一覧にPagesが載るが、注記に「組織がGitHub Enterprise Cloudを使っている必要がある」とある。Teamだけでは足りない。
- 組織のFree：Privateのリポジトリでのpagesについて、このページには記述がない（別の資料では、Publicでなければならないとされる。[資料：GitHub Pagesの公開の手順](web-github-pages-setup.md)）。
- GitHub Enterprise Cloudの組織：見られる人を限った（非公開の）Pagesのサイトを作れる。
- 一つのアカウントのユーザーまたは組織のサイトは一つ、一つのリポジトリのプロジェクトのサイトは一つ。訪問者のIPアドレスは安全のために記録される。
- この資料には、GitHub Education（学生向けのプログラム）の内容は載っていない。

## 注意

- 取得した内容は要約を通したものなので、プランの表そのものと細部が違う可能性がある（要確認）。
- 授業の組織（tokyo-city-university）がどのプランかは、この資料からは分からない。
