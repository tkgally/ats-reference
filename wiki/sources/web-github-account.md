# 資料：GitHubのアカウント、二要素認証、共同作業者の招待（GitHub Docs）

GitHubのアカウントを作って使い始めるときに関係する、二要素認証、学生向けの特典（GitHub Education）、リポジトリへの招待についての公式ドキュメントの要約です（2026年10月7日に確認）。

## 内容の要約

- 二要素認証：GitHubは、コードを投稿する多くのアカウントに二要素認証（パスワードに加えて、スマートフォンのアプリなどで本人を確かめるしくみ）を求めている。対象になったアカウントには、設定のための猶予期間がある。メールでの確認は二要素認証の代わりにならない。
- GitHub Education：学生は、在籍を証明するもの（在籍が分かる学生証など）を示して申し込む。学校によっては大学のメールアドレスが必要になる。13歳以上であることが条件。認証されると、GitHub Copilotを無料で使える特典などがある（[資料：学生向けのGitHub Copilot](web-github-copilot-students.md)）。
- 公開範囲：リポジトリは公開（Public、インターネット上のだれでも見られる）か非公開（Private、自分と共有した人、組織のリポジトリでは組織の一部のメンバーが見られる）を選べる。GitHub Enterprise Cloudを使い、エンタープライズのアカウントが持つ組織では、組織内（Internal）の公開範囲も選べる。
- 共同作業者の招待：個人のリポジトリでは、Settings → Collaborators → Add people から招待する。招待された人がメールやGitHubの通知から承諾すると、書き込めるようになる。招待は7日で期限が切れる。
