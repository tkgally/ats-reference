# 資料：ChatGPT、Claude、Geminiの料金とデータの設定

主な汎用AIチャットサービス（ChatGPT、Claude、Gemini）と、学校のアカウントで使うMicrosoftのCopilot Chatについて、各社の公式ページで確かめた料金とデータの設定の要約です（2026年10月7日に確認）。

## 資料の情報

- ChatGPT（OpenAI）：料金 [https://chatgpt.com/pricing](https://chatgpt.com/pricing)、データの設定 [https://help.openai.com/en/articles/7730893-data-controls-in-chatgpt](https://help.openai.com/en/articles/7730893-data-controls-in-chatgpt)
- Claude（Anthropic）：料金 [https://claude.com/pricing](https://claude.com/pricing)、データの設定 [https://privacy.claude.com/en/articles/12109829-how-do-i-change-my-model-improvement-privacy-settings](https://privacy.claude.com/en/articles/12109829-how-do-i-change-my-model-improvement-privacy-settings)
- Gemini（Google）：料金 [https://gemini.google/subscriptions/](https://gemini.google/subscriptions/)、データの設定 [https://support.google.com/gemini/answer/13594961](https://support.google.com/gemini/answer/13594961)
- Microsoft 365 Copilot Chat（職場・学校のアカウント）：[https://support.microsoft.com/en-us/privacy/data-protection-when-using-microsoft-365-copilot-chat-for-work-or-school](https://support.microsoft.com/en-us/privacy/data-protection-when-using-microsoft-365-copilot-chat-for-work-or-school)
- 確認した日：2026年10月7日
- 種類：ウェブ上の資料（エージェントが調べたもの。`raw/`の資料ではない）

## 内容の要約

### 料金

ChatGPT、Claude、Geminiのいずれにも、利用量などに制限のある無料のプランと、月額およそ20ドルの個人向け有料プランがあり、さらに上位のプランもあります（2026年10月7日時点）。料金や内容は変わりやすく、国や地域によって異なることもあります。

### 会話がモデルの学習に使われるかどうかの設定

| サービス | 設定の場所（英語の画面の表記） |
| :---- | :---- |
| ChatGPT | Settings → Data controls → Improve the model for everyone |
| Claude | Settings → Privacy → Help improve Claude |
| Gemini | アクティビティの設定で「Keep Activity」をオフにする（オフでも会話は72時間保存される）。一時的なチャットの機能もある。 |

日本語の画面では表記が異なります。

### 学校のアカウントで使うCopilot Chat

Microsoftによれば、職場や学校のアカウントで使うMicrosoft 365 Copilot Chatには「エンタープライズデータ保護」が適用され、入力や回答が基盤モデルの学習に使われることはないとされています。TCUアカウントでの利用にこれがどう当てはまるかは、大学の案内で確かめる必要があります（要確認）。
