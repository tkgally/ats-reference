## 内容の要約

トークン：

- トークンは言語モデルが扱う最小の単位で、単語、単語の一部、文字、ときにはバイトに当たる。
- Claudeでは、一つのトークンが表す文字数はモデルと言語によって違う。Claude 4.7以降のモデルは新しいトークナイザー（文章をトークンに分ける仕組み）を使い、同じ文章でも以前のモデルより約30パーセント多いトークンになる。以前のモデルでは、一つのトークンが英語の約3.5文字に当たった。
- 正確な数は、使うモデルを指定したトークン数の計算機能で調べる。
- 普段は文章の水準でやり取りするのでトークンは見えないが、モデルへの入力と出力を正確に見るときに関わってくる。
- 大きなトークンは処理の効率がよく、小さなトークンは見慣れない言葉を扱いやすい。分け方は、性能や語彙の大きさに影響する。
- 最初のトークンが出るまでの時間（TTFT）は、応答の速さの指標の一つ。

そのほかの用語：

- コンテキストウィンドウ：モデルが答えを作るときに参照できる文章の量。学習に使った大量のデータとは別の「作業記憶」。
- 温度（temperature）：出力のランダムさを決める設定。高いと多様で創造的に、低いと確実な選択に寄る。温度を0にしても、同じ入力が毎回同じ出力になるとは限らない。
- 事前学習：大量のラベルなしの文章で、前の文脈から次の言葉を予測するように言語モデルを最初に訓練する過程。事前学習だけのモデルは指示に従うのが得意でなく、ファインチューニングやRLHFで使いやすくする。
- RLHF：人間が複数の文章例に順位をつけ、強化学習でモデルが上位の文章に近い出力を好むようにする訓練。Claudeはこれで役に立つアシスタントになるよう訓練されている。
- HHH：役に立つ（helpful）、正直（honest）、無害（harmless）の三つからなる、Claudeの訓練の指針となる研究の枠組み。
- レイテンシー：プロンプトを送ってから出力を受け取るまでの遅れ。TTFTはその最初のトークンが出るまでの時間。
- ファインチューニング：学習済みのモデルに追加のデータで学習させ、特定の分野や文体に合わせること。
- RAG（検索拡張生成）：外部の知識ベースから関係する情報を探し、質問と一緒にモデルへ渡して、答えの根拠を確かにする手法。
