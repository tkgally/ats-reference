# README

リポジトリの入り口に置いて、プロジェクトの目的や使い方を説明するファイル、READMEについてのページです。

## READMEとは

GitHub公式のドキュメントによれば、READMEはリポジトリにあるファイルで、プロジェクトの目的、役立つ点、始め方、助けを得る方法、維持している人を説明します。訪問者が最初に目にするので、使い始めるために必要なことに絞って書くのがよいとされます。長い文書はWikiなどに置きます（[資料：IssuesとREADME](../sources/web-github-issues-readme.md)、2026年10月12日に確認）。

## 置き場所と表示

- 置き場所：GitHubは`.github`ディレクトリ、リポジトリの直下、`docs`ディレクトリの順に探し、複数あれば先に見つかったものを表示する。
- 表示：GitHubが整形して表示し、見出しから目次を作る。書式は[Markdown](markdown.md)で書く（拡張子`.md`）。
- リンク：相対リンクと画像のパスは現在のブランチに合わせて調整されるので、相対リンクが勧められている。
- 大きさ：500 KiBを超える部分は切り捨てられる。

## この知識ベースでは

このリポジトリの`README.md`は、リポジトリの説明と[目録](../index.md)へのリンクを置く入り口になっています（[AGENTS.md](../../AGENTS.md)）。自分のプロジェクトの知識ベースでも、同じようにREADMEを入り口にするとよいでしょう（[LLM Wiki](llm-wiki.md)）。
