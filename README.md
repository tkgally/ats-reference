# ats-reference

東京都市大学で2026年度後期に開講される「AIとの探検ゼミナール」（ATS）のための知識ベースです。[LLM Wiki（日本語版）](llm-wiki-j.md)の考え方にもとづき、AIエージェントが資料を読んでWikiを書き、維持しています。

- Wikiの入り口：[wiki/index.md](wiki/index.md)（全ページの目録）
- 全体の概観：[wiki/overview.md](wiki/overview.md)
- 作業記録：[wiki/log.md](wiki/log.md)
- エージェント向けの約束事：[AGENTS.md](AGENTS.md)
- 元資料：[raw/](raw/)

資料を追加するときは`raw/`にファイルを置き、エージェントに「取り込んでください」と頼みます。Wikiについて質問したり、点検を頼んだりすることもできます。手順は[AGENTS.md](AGENTS.md)に書いてあります。
